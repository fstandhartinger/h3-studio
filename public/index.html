    MiniMax H3 responds to an explicitly staged prompt far better than to a single sentence. Four sections, in this order:

    1. Look — one paragraph of subject, lens, lighting and setting. No timing here.
    2. Timeline — bracketed windows [0s‑2s]. Put every camera move and action in a window. Dialogue goes inside a window as …and says clearly in English: "the line". The quoted text is what gets spoken.
    3. Camera grammar — one continuous shot, or hard cuts. Saying "no zooms" actually suppresses zooms.
    4. Audio — the headline feature. Name the ambience and where it sits in the stereo field, the voice and its exact time window, and every music or sfx entrance by timestamp. This is not a TTS track bolted on afterwards — the model decodes picture and stereo sound from the same latent, so anything you don't specify it will invent for you.

    Finish with negative constraints such as no on‑screen text, no subtitles. Eleven languages are supported for dialogue, but naming the language in the line ("says clearly in English") is what makes it reliable.

    Leave empty for a fresh random seed each run. The server returns the seed it used, so any clip can be reproduced.
